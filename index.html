Sobre o desenho

Animação adulta criada por Justin Roiland e Dan Harmon e exibida pelo Adult Swim desde 2013. Herdeira direta da cultura de animação dos anos 90 e 2000, a série acompanha o cientista Rick Sanchez e seu neto Morty Smith em viagens por dimensões paralelas.

Multiverso infinito

Cada dimensão tem a sua própria versão dos personagens, o que explica tantos Ricks e Mortys diferentes dentro do catálogo da API.

Elenco completo

A API cataloga cada personagem com imagem, status de vida, espécie, gênero, origem, localização atual e episódios em que apareceu.

Dados em tempo real

Nada está fixo no HTML: a cada carregamento da página o JavaScript faz uma requisição fetch e monta a interface do zero.

A API utilizada

A Rick and Morty API é pública, gratuita, somente leitura e não exige cadastro nem token de acesso.

Regras de acesso e endpoints da Rick and Morty API
ItemDescrição
URL basehttps://rickandmortyapi.com/api
AutenticaçãoNão é necessária: sem token, sem chave e sem cadastro
MétodoGET (API somente leitura)
Endpoint usado/character?page=1&name=&status=&species=&gender=
FormatoJSON com as chaves info (paginação) e results (lista)
Paginação20 personagens por página, 42 páginas no total
Limite de requisiçõesSem limite rígido documentado; uso responsável e com cache local
Erro comum404 quando nenhum personagem atende aos filtros
